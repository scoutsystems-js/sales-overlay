"Trust/proof/skepticism" = fear. (H082, H085, H398, H428, H465)
- **A true objection is post-price/post-ask resistance.** `risk_signal` = earlier doubt; `barrier` = external constraint. The decision test: can the prospect change it by deciding differently? Yes → objection, no → barrier. Questions are not automatically resistance. No precedence rule between types. Speaker-anchoring guard rejects (never retypes) a barrier/risk/objection on a closer line. (H092, H100)

## 6 · Verification and testing discipline

These are the rules behind most of the history file. The families recur; each rule below is the family, with its instances as pointers.

- **THE MOST-USED PAGE HAS AN EXECUTED GUARD (H710): `test/calls-list-clickable.test.js` renders the review header by CALLING it (a missing helper is a ReferenceError there, not on Justin's screen) and renders the Calls rows in Electron and CLICKS them — the row opens, the name renames without opening, the tag sets without opening, a marked row has no way in.** It exists because the suite was green while the page was down: an edit that replaced a block of the page took three functions with it, and nothing executed the header. **When you replace a block by slicing between two markers, print what the slice contains before writing** — the rename functions sat between the follow-up comment and its function. (H710)
- **A GUARD PROTECTING MONEY, ACCESS OR SCOPE MUST EXECUTE THE ROUTE AND ASSERT THE CONSEQUENCE — never assert that a line of code exists. And it is proven by planting the defect TWICE: once REMOVING the call, once KEEPING the call and DISCARDING ITS EFFECT (gate result ignored, comparison `&& false`, confirm answer dropped, scope on a dead lookup). A guard that survives the second plant guards nothing.** Standing rule, Justin 2026-09-02, earned by sweep block 2: eight such guards survived the second plant with the full suite green. "Executes something" is not "executes the thing" — a sibling that executes the helper does not cover the route. (H665, H666)
- **Execute the real entry point.** Testing a helper in isolation and grepping for its name are the same check twice — both prove it EXISTS, neither that it RUNS. Drive the real render/route/pivot with injected state; assert the CALL SITE and the CONSEQUENCE (the branch, the slot it needs), not the mention. **Proved at scale 2026-09-02: eight spend/permission/scope guards stayed green — with the FULL suite, 2132/2132 — when the gate was called and its result ignored, the comparison made `&& false`, the confirm awaited and its answer dropped.** The plant that proves a guard is "call kept, effect removed", never only "call removed". (H665) The dead-call-site family: H019, H235, H239, H564, H644, H571, H193, H228, H236.
- **Restore the defect and count the failures.** A guard is proven only when the exact defect makes it fail; a mismatch between defects restored and guards failed is the signal. Write a removal guard BEFORE the removal and see it fail. Back up every changed file (`git stash -u`), and assert the revert took effect before trusting the result. (H148, H510, H103, H313)
- **Every anchor asserted present before it is compared** (`indexOf` returns −1 and `−1 < x` is true); assert the slice length with a per-function floor and pass `fromIndex`; select by CONTENT never by position (`all[0]`, `.pop()`, first match); anchor past `<body>` and past archived copies. (H190, H528, H549, H149, H079, H633)
- **Derive guards from the source of truth; never pin a literal, an encoding, a version, a loop-variable name, or the shape of a list.** A guard that fails on the correct change is pinned to an implementation, not a property — re-pin, and assert the old form ABSENT. A guard may enshrine the defect it was written to prevent. (H325, H511, H527, H565, H587, H645, H529)
- **Scope equals claim.** A check's verdict is narrower than its claim in three ways — SCOPE (what it looked at), INVENTORY (targets it enumerated), RANGE (one point on a continuous axis). State the scope beside the verdict; enumerate by CAPABILITY (the operation nothing can avoid), not by the string you expect; a search built from the hypothesis cannot disconfirm it. A count over a file is not a per-site assertion. (H278, H276, H213, H303, H324, H164, H390, H516, H455, H387)
- **A check that can pass by finding nothing needs a floor** — assert the sample size, that the control moves, that the fixture exercises the branch, that the probe returns different answers for cases that differ, that a planted defect is found. A control that can decline to exercise its property is not a control. (H332, H080, H357, H300, H578, H416, H463)
- **When a check reports a problem, confirm the check is sound first** — the cheapest test is whether its output contradicts something already visible (a green mark read as white ink; a screenshot vs a pixel count; two facts in one result that cannot both be true). Read the right property, in the right coordinate space, in the right region. (H200, H513, H566, H206, H287, H367, H595)
- **The shared stripper is string-aware and EXECUTED against the five killers and the live dashboard on every run (`test/one-stripper.test.js`, H682); the count of private copies is a ratchet — it may fall, never rise. Convert a private copy by hand (they slice, count and collect as well as strip), never by script; the eleven block-first files go first.**
- **A detector is scored on planted positives AND negatives before its output is read, and prints RAW line numbers** (`backend/sweep/`, `sweep/raw-line.js`; the one stripper is `sweep/strip.js`). A measurement quoted in a finding uses the code's EXACT filter. (H663)
- **Strip comments — line comments FIRST, then block; leading AND trailing — before any text match, in tests AND in deploy checks;** this codebase archives removed code in place, so a raw grep reports the documentation of a rule as a violation of it (11 guards carried the ordering bug). Strip for matching; run the RAW source for execution. Never quote removed syntax in the prose explaining a removal. (H131, H184, H233, H306, H128, H342)
- **Measurement is not a composition test; a subjective target needs a LOOK.** Ask first: "if all my numbers came back perfect, would that prove it is right?" Screenshot the worst instance, not the default one; sample the RENDER, not the source; for anything about appearance enumerate `getComputedStyle` over the live page — a stylesheet grep cannot show a style that does not live in it, and predicting classes has been wrong three times. A block's `getBoundingClientRect` cannot see overflow (`scrollWidth` vs `clientWidth`) or ancestor clipping. (H209, H208, H205, H206, H646, H649, H163, H543)
- **Verify across the range a layout moves through;** derive values from the constraint (`fontSize = width / k`, k measured per face and per weight/tracking), never pick a number that passes today; a criterion is not a constant; a derived value inherits the case it was derived from; a stroke is a solve, not a division. (H213, H216, H199, H270, H272, H273)
- **Fixtures come from the producer, never from memory** — six invented shapes produced six false defects; check `cached` before reading a before/after; a hash-only navigation keeps module state; forge the actor at the layer below the credential. (H555, H480, H351, H150, H632, H355)
- **`node -c` proves a file parses, nothing more:** it cannot see an unresolved identifier, a nested declaration at the wrong brace depth, a missing import, or a truncated-but-valid file. Count references per identifier; append parameters, never insert mid-list; assert an edit did not shrink the file (per-edit cap) and that brace counts balance; every edit script writes AND prints; no optional-prefix regexes; scope scripted edits by enclosing function and assert the match count; never `node -e` with quotes in the payload. (H385, H476, H389, H102, H330, H495, H588, H622, H341, H203, H522)
- **Width claims come from a same-origin `<iframe>` at that width, never from `resize_window`** (a no-op on a maximised window that still reports success — `innerWidth` is the check); a hash-only `navigate` keeps the old document AND its stylesheet, so a deploy is confirmed only after a path change. (H687)
- **The browser harness:** synthetic clicks are delivered only briefly after a fresh navigation — pair every click conclusion with a delivery count; `computer` takes SCREENSHOT-SPACE coordinates (scale by `screenshotWidth / innerWidth`); a hidden tab freezes the animation CLOCK, so pause before capturing and scrub `getAnimations()` rather than waiting; native `confirm()`/`prompt()` cannot be driven; reload evidence (URL, restored state) is trustworthy, gesture evidence needs a human; the unauthenticated-iframe recipe suppresses `init()` and cannot verify anything `init()` does. (H554, H366, H541, H386, H619)
- **Reporting:** a number in a report is a claim until re-derived — including your own; a caveat carries its evidence or its uncertainty; a mid-run measurement is not a result; sort-by-size is not sample-by-frequency; a mean over a bimodal field describes neither mode; a sample cannot move a per-user statistic; a rate is only actionable per group; state the growth term of an estimate; state which question a measurement answers. (H290, H295, H152, H473, H207, H075, H151, H218, H592)
- **Diagnosis:** a clearance is only as good as the symptom it was tested against — re-open every clearance when a sharper report arrives; establish which failure it is before scoping (display filter vs incomplete delete); enumerate by capability then execute rather than reason from an ordering model; two changes in one block invite a false causal story — measure whether the fix explains the symptom; a fix shipped beside the thing it breaks reads as a relapse. (H053, H071, H050, H568, H411, H054)
- **Tests survive their scaffolding: convert, do not delete;** a test may pin a known defect with its reason and expiry inside the test; a converted test's TITLE is part of the conversion; a conversion aimed at another dead thing is not one; a guard's floor moves with its population with the reason at the assertion; one exemption in a guard is doing real work — do not become the second. (H191, H095, H524, H586, H602, H580, H579)
- **A comment that asserts an ordering or a parity the code does not enforce is worse than none** — establish it structurally or in a test, or write "assumed". The stale-load-bearing-comment family: H551, H552, H049, H452, H629.
- **When a value's MEANING changes but its TYPE does not, RENAME it** so every reader fails loudly (`repIds`→`memberIds`, `at_or_above`→`meeting`, `hard`→`purge`). When a shared carrier (state field, hash, container, word) changes meaning, the risk is its OTHER readers — grep them all. (H125, H544, H221, H550, H135, H136, H137)
- **A constant typed twice is pinned by IDENTITY where an import is possible (`===` on the same array — a copy that agrees fails) and by EXECUTING the page's literal as a set where it is not.** The four ③ pairs (objection classes, coachable/negative types, worker/page handling types, `by_rep`/`bar_rep`) are wired that way; a guard that pinned the literal `100` was the drift it claimed to prevent. (H685)
- **Replace a guard by routing around it, never widening it;** a rule implemented at the call site is a rule most call sites do not have — put it in one module and guard that no site hand-rolls it. (H237, H544)
- **A published claim about unbuilt behaviour is a commitment nobody chose** — decide, build, then write the sentence. (H196, H545)
